# Combinados da aula

## Como trabalhar comigo
- Responda em português simples: sou iniciante.
- Faça somente a etapa que eu pedir.
- Antes de executar qualquer código, explique o que ele faz e espere eu escrever "pode executar".
- No fim de cada etapa, diga: o que mudou, como eu confiro e qual é o próximo passo.

## Arquivos
- Os dados de entrada estão em dados/. Nunca altere esses arquivos originais.
- Grave tudo o que for gerado (análises, gráficos, relatórios, modelos) em resultados/.
- Use o Python da pasta .venv (no Windows: .venv\Scripts\python).
- As skills do projeto ficam em .agents/skills. Quando eu citar uma skill, leia o SKILL.md dela.

## Honestidade
- Faça as contas com código, nunca de cabeça ou por estimativa.
- Não invente dados, métricas, resultados de testes ou chamadas de ferramentas.
- Quando eu pedir MCP, use a ferramenta MCP e mostre qual ferramenta chamou.

## Machine learning
- Nunca use o alvo (Churn) nem identificadores (customerID) como entrada do modelo.
- Ajuste a preparação dos dados somente com os dados de treino.
- Escolha o modelo pela validação. O teste final é usado uma única vez.
